03. Intelligent Search Slide 5

More Than Simple Keyword Search

Questions come in different forms. Local Search automatically indexes metadata, tags, and relationships to support three search techniques simultaneously:

  • 1. Semantic / Meaning Search: Finds concepts even without exact keyword matches.
  • 2. Graph Relationship Search: Maps how Document A connects to Document B.
  • 3. Structured Fact Queries: Instantly looks up exact tags, dates, or specifications.

07. Reliability Slide 9

Fail-Safe Retrieval Flow

What if a brand-new file hasn't been indexed yet? Local Search guarantees complete reliability through a 2-step safety net:

Path A (Index First): Fast, intelligent retrieval across pre-indexed local sources.
Path B (Fallback Scan): Scans raw files directly if index results are insufficient.
