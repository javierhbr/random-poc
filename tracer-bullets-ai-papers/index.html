Spec-driven development for AI agents

Make your AI agent work like a senior engineer.

Left alone, AI coding agents take the shortest path — skip the spec, guess the architecture, skip the tests. Uncle Dev overrides that at every phase: spec first, test as it goes, review before commit.

Install Uncle Dev
Read the intro

Spec first

Writes a spec and waits for approval before coding.

Test as it goes

Builds one tested slice at a time, then debugs.

Review before commit

Reviews its own diff at a QA gate before shipping.
