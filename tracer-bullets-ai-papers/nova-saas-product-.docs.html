Docs Core API Authentication

Authentication

The Nova API uses API keys to authenticate requests. You can view and manage your API keys in the Dashboard Settings.

Bearer Tokens

Authentication to the API is performed via HTTP Bearer Auth. Provide your API key as the basic auth username value. You do not need to provide a password. 

curl https://api.nova.dev/v1/projects \
  -H "Authorization: Bearer nv_live_xxxxxxxxx" \
  -H "Content-Type: application/json"

Keep your keys secure

Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, and so forth.
